01Mechanistic Forecast · Input-Uncertainty Envelope

SIMULATED · MONTE CARLO 500 seeded trajectories · 2.5 / 50 / 97.5 percentiles
The band shows how the twin responds to assumed day-to-day variation in its inputs (sleep, recovery, workload, exercise, CO₂, dose rate). It is not a calibrated predictive interval and not a clinical prognosis.

02Forecast Equation

xt+1 = fmech(xt, ut + δut, e; θ)
fmech: the same discrete daily equations as the Python simulator (see Data & Methods).
δut: daily Gaussian input jitter (sleep σ 0.5 h, recovery σ 0.3 h, workload σ 5 %, exercise σ 10 min, CO₂ σ 0.3 mmHg, dose rate σ 15 %).
The ML residual term gML described in the docs is not applied in this build.

      03Twin Equations (as implemented)

      w = workload/100, g = gravity, wake = 24 − sleep. Same equations in Python and JS.

      1. Sleep pressure S (S₀ = 22)
      St+1 = clip(St + 0.22·[1.15·(wake − 16) + 8.5·(w − 0.55) − 2.65·(sleep − 7.5) − 1.40·(rec − 1.5) + 1.25·max(0, pCO₂ − 2.5)], 6, 95)
      2. Vagal tone RMSSD (RMSSD₀ = 48.2 ms)
      target = 48.2 − 14·(w − 0.5) + 3.6·(rec − 1.5) − 0.24·(St+1 − 22) + 0.04·min(ex, 90)
      RMSSDt+1 = clip(RMSSDt + 0.28·(target − RMSSDt), 14, 82)
      3. Bone mineral density Δ (%)
      BMDt+1 = BMDt − 0.0433·(1 − g) + 0.0330·(ex/120) − 0.012·max(0, w − 0.70)·max(0, (8 − sleep)/4)
      4. SANS risk proxy
      SANSt+1 = clip(10 + 24·(1 − e−(t+1)/18)·(1 − g) + 8.4·max(0, pCO₂ − 2)1.25 − 4.5·rec/3 + 0.15·max(0, St+1 − 40), 5, 96)
      5. Composite readiness
      R = 0.25·(100 − S) + 0.25·clip(RMSSD/55·100, 20, 100) + 0.25·clip(100 − 8·|BMD|, 20, 100) + 0.25·(100 − SANS)

        05Scientific Responsibility

        Provenance labels. Every number on this dashboard is tagged SIMULATED, DERIVED or ENCODED ANCHOR. No value on screen is a live NASA measurement.

        Research prototype. ASTRAVIVE is an exploratory simulation sandbox. It is not a clinically validated physiological twin or a medical device.

        Correlation vs causation. Shapley attributions describe model behaviour and do not establish biological causation.
